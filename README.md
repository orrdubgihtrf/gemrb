## Overview

GemRB is a portable open-source reimplementation of BioWare's Infinity Engine, enabling Baldur's Gate I & II, Icewind Dale I & II, and Planescape: Torment to run natively on Linux, macOS, iOS, Android, and modern Windows. Developed over two decades as a community project, it corrects long-standing engine bugs, improves stability on modern hardware, and opens the Infinity Engine games to platforms where the original engine never ran.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **GemRB** delivers the features you need in a clean, intuitive package.

> Official website: [gemrb.org](https://gemrb.org)

## Key Features

| Feature | Description |
|---------|-------------|
| **Six Classic CRPGs** | Full support for all Infinity Engine titles from Baldur's Gate to PST |
| **Modern Platforms** | Runs natively on Linux, macOS, iOS, Android, and modern Windows |
| **Bug Corrections** | Long-standing original IE bugs corrected in the open-source codebase |
| **Original Data Compat** | Uses unmodified original game data installations without patching |
